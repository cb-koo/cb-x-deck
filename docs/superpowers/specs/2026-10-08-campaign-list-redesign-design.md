- 브랜치 `cb-koo/campaign-list` (origin/main에서) · 서버 변경은 목록 조회 칸 추가만 · 마이그레이션 없음
- 시안(확정): https://claude.ai/artifact/FRbWBuxZDGyJMm48GCf2BS — 1번 장면(목록), 2번 장면 중 ⋯ 메뉴(보관 부분 제외)
- 리서치: ~/claude-outputs/20261007_캠페인목록_UI패턴_리서치.md

## 1. 왜
캠페인 v2(`/campaigns/flow`) 왼쪽 목록이 이름 + `8/24 월 ~ 8/30 일 · 작업 N건` 글자만 나열돼 빽빽하고, 어떤 캠페인이 잘 가고 있는지 안 보인다. 검색·묶기·관리 동작도 없다.

## 2. 결정 (koo)
- 목록 폭 280 → **360px**.
- 세 섹션: **장기 캠페인 / 주차 캠페인 / 지난 캠페인** (작은 왼쪽 정렬 제목, 선 없음).
- 주차 묶음 제목 = **주차 이름 + 캠페인 수 알약만**(날짜·작업 요약 없음). 접기 아이콘 뚜렷하게.
- 순서: 장기 캠페인 → 이번 주(펼침) → 다음 주(캠페인 있으면 펼침, 없으면 접힘 `0개`) → 지난 캠페인(지난 주·그 전 주…, 전부 접힘, 흐린 색). 지난 캠페인은 최근 2개 주차만, 나머지는 `더 보기`.
- 행 = **색 점 + 클라이언트 이름(+ 꼬리말) + 진행 막대 + `게시 n/m`**, 한 줄 52px.
- 위: 검색, `묶어 보기 [주차 | 클라이언트]`.
- 행 메뉴 없음(koo 10-08 — 편집·삭제는 캠페인 상세 머리글에서)
- 옛 화면(`/campaigns`, 보관 메뉴)은 지금 목록 그대로 둔다.

## 3. 규칙
### 3-1. 장기 캠페인
- 기간(ends − starts + 1일)이 **7일 초과**면 장기. 7일 이하면 주차 캠페인.
- 장기 캠페인 중 **종료일이 지난 것**은 장기 섹션에서 빠져 **지난 캠페인**의 "끝난 날이 속한 주차"로 간다. 이번 주 안에 끝난 장기 캠페인은 그 주가 끝날 때까지 이번 주 묶음에 남는다.
- 장기 섹션은 묶음 제목 없이 행만, 시작일 오름차순(먼저 끝나는 게 위가 아니라 먼저 시작한 게 위). 장기 캠페인이 없으면 섹션 자체를 그리지 않는다.

### 3-2. 주차
- 캠페인의 주차 = **시작일이 속한 월~일 주**(장기에서 내려온 것은 종료일의 주). 주 이름은 캠페인 이름 규칙과 같은 목요일 판정(`suggestCampaignName`의 `M월N주차`).
- 오늘이 속한 주 = `이번 주 · {M월N주차}`, 그다음 주 = `다음 주 · {…}`, 그 전 주 = `지난 주 · {…}`, 더 이전 = `{M월N주차}`. 다음 주 이후(2주 이상 뒤)는 `{M월N주차}`로 다음 주 아래에 이어서(예정이 드물어 따로 섹션을 두지 않는다).
- 이번 주·다음 주 묶음은 캠페인이 0개여도 그린다(`0개`, 이번 주는 펼쳐서 `아직 캠페인이 없어요` 한 줄). 지난 주차는 캠페인이 있는 주만.
- 묶음 안 순서: 클라이언트 이름 가나다순(같은 클라이언트면 시작일순).

### 3-3. 행
- 이름: 캠페인 이름이 `{클라이언트}_{M월N주차}` 꼴이면 **클라이언트 이름만**, 아니면 클라이언트 이름 + 꼬리말(캠페인 이름에서 `{클라이언트}_`를 뗀 나머지, 예 `도쿄상담회 플모`, `10월 방문협찬`). 클라이언트가 없으면 캠페인 이름 전체.
- 진행 막대(56×6): 게시(진한 파랑) / 배정됐지만 미게시(옅은 파랑) / 미배정(바탕). 분모 = 취소 뺀 작업 수. 작업 0건이면 빈 막대 + `작업 없음`.
- `게시 n/m`.
- 색 점(자동, 사람이 고르지 않음) + 마우스를 올리면 판단 문장(툴팁):
  | 색 | 조건(위에서부터 먼저 맞는 것) | 문장 |
  |---|---|---|
  | 회색 | 시작 전 | `{M/D}에 시작해요` |
  | 초록 | 작업 ≥ 1, 전부 게시 | `모두 게시됐어요` |
  | 빨강 | 기간이 끝났는데 미게시 또는 미배정 ≥ 1 | `기간이 끝났는데 게시 안 된 작업 {n}건` |
  | 노랑 | 그 밖(진행 중, 미게시·미배정 있음) | 미배정 있으면 `미배정 {a}건 · 게시 대기 {b}건`, 없으면 `게시 대기 {b}건` |
  | 회색 | 작업 0건(진행 중·종료) | `작업이 없어요` |
- 선택된 행: 옅은 파란 바탕 + 왼쪽 3px 파란 선.

### 3-4. 위쪽
- `캠페인` 제목 + `+ 새 캠페인`(기존 생성 창). 옛 설명 문단은 뺀다.
- 검색: 캠페인 이름·클라이언트 이름에 포함(대소문자·공백 무시). 검색 중엔 모든 묶음을 펼치고 일치하는 캠페인 없는 묶음은 숨긴다. 결과 0건이면 `찾는 캠페인이 없어요`.
- `묶어 보기 [주차 | 클라이언트]` — 클라이언트 묶기: 클라이언트별 묶음(최근에 시작한 캠페인이 있는 클라이언트가 위), 묶음 안 최근 시작순, 진행 중·예정이 있는 클라이언트는 펼침·나머지 접힘. 섹션 제목 없음. 클라이언트로 묶으면 행 이름은 클라이언트명 뒤 부분(예 10월2주차)만 보인다. 선택은 브라우저에 기억(`campaign-list-group-by`).

### 3-5. 행 메뉴
- 행 메뉴 없음(koo 10-08 — 편집·삭제는 캠페인 상세 머리글에서)

## 4. 데이터
`CampaignRow`에 `progress: { planned: number; posted: number; assigned: number; unassigned: number }` 추가 — 취소 뺀 작업 기준. assigned = 인플 배정됐고 미게시, unassigned = 인플 미배정(미게시). planned = posted + assigned + unassigned. 목록 SELECT에서 한 번에 센다.

## 5. 업데이트 소식
`개선` — `캠페인 목록이 주차별로 묶이고 진행 상황이 한눈에 보여요`.

## 6. 범위 밖
복제·보관, 주 단위 현황 페이지(별도 작업), 옛 `/campaigns` 화면.
