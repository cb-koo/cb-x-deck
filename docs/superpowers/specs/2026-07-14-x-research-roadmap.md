# cb-x-deck X 콘텐츠 리서치 기능 — 4축 로드맵

날짜: 2026-07-14 · 상태: 승인됨(박구건, Phase 1부터 진행) · 근거: `~/claude-outputs/X콘텐츠리서치-방법론조사-클리닉브릿지선별-20260714.md`(방법론 조사 + getxapi 실측)

## 배경

X 콘텐츠 기획의 병목인 "탐색(글감·훅·포맷 발굴)"을 X **내부**에서 직접 발굴하는 기능. 리서치는 2트랙 — ①웹 리서치(exa, X 바깥 뉴스·블로그→키워드, 이미 v1 구현됨) ②**X 리서치**(이 로드맵). 4축은 "신뢰성 선별 통과 방법론 ∩ getxapi로 실증된 구현 가능성"의 교집합.

## 스펙 전 명료화로 확정된 제품/운영 요소

| 요소 | 결정 |
|---|---|
| A. 사용 빈도 | **주간 루틴** — 저장한 검색·계정을 정기적으로 재실행하는 재사용·정기성이 무게중심 |
| B. 통합 구조 | **X 리서치 본체 = 덱.** 벤치마크 검색=`search` 컬럼 확장, 계정 필러=`watchlist` 확장, 큐레이션=보관함/후보 재사용. `리서치` 페이지는 온램프(검색어 발굴→덱 컬럼 생성)+종합 리포트 전용(현재 exa 웹 트랙). "이미 뭘 볼지 안다"=덱 / "뭘 볼지 찾는다·기간 요약"=리서치 페이지 |
| C. 데이터 모델 | 트렌드(④)만 신규 시계열 저장 필요. 나머지는 기존 `tweet`/`deck_column`/`candidate` 위에 얹힘 |
| D. 사람 개입 | v1은 담당자 수동 선별(기존 보관함). **저장/버림 신호를 기록**해 두어 나중에 자동 관련성 필터 학습에 사용 |
| E. 행선지 | 보관함 → 기획 참고 (신규 다운스트림 불필요) |
| F. 규제 | 薬機法·体験담 리스크 패턴에 **가벼운 경고 배지**만(필터링 안 함) |

## 실측이 부과한 구현 제약 (모든 축 공통)

- **OR 그룹은 반드시 괄호**로 묶어야 min_faves가 전체에 적용됨(`A OR B min_faves:N` = `A OR (B min_faves:N)`로 오파싱). cb-x-deck `queryBuilder.ts`는 이미 괄호 침 → 회귀 테스트로 고정.
- **min_faves 등 엔게이지먼트 임계는 `type=Top`에서만 유효**(Latest는 무시).
- **임계치는 키워드 폭에 따라 가변**(브로드 3,000~10,000 / 좁은 시술 100~300). 고정 300 폐기.
- 인용 역탐색(quotes) **엔드포인트 부재(404)** → 인용 확장 제외. 리플/스레드/리포스터는 전용 엔드포인트로 가능.
- 리스트 탐색은 `/twitter/list/members?listId=` 존재하나 **큐레이션된 listId 선행 필요**. 커뮤니티 가입=쓰기 액션이라 제외.

## 4축 로드맵 (단계별)

### Phase 1 — 벤치마크 검색 (축 ①) + 큐레이션 신호 + 규제 경고  ← **지금 스펙/구현**
기존 검색 컬럼 확장: `min_retweets`/`min_replies` 추가, min_faves 가변화, Top 모드·OR 괄호 가드레일(+회귀 테스트), "재사용 가능한 벤치마크 검색"으로 저장. 보관함 저장/버림을 신호로 기록(향후 자동필터용). 薬機法 경고 배지. — 가장 적은 노력·가장 빠른 주간 사용 가치, 기존 확장이라 리스크 낮음.

### Phase 2 — 계정 필러 분석 (축 ②) + 확장 탐색 (축 ③)
워치리스트 계정 트윗을 주제별로 묶어 게시량 대비 인게이지먼트 비교 뷰(경쟁 계정의 저평가 고성과 주제 발굴). 트윗 카드에 리플/스레드/리포스터 확장(getxapi 전용 엔드포인트, 실측 완료).

### Phase 3 — 트렌드 + 기간 종합 (축 ④)
정기 수집 누적 위에 해시태그·키워드 시계열 트렌드(이번 주 vs 지난주 델타) + getxapi 수집 → Claude 기간 종합 요약(Grok 제품 대체, 신규 도구 불필요). 데이터 누적이 전제라 마지막. **배치**: 트렌드 "모니터링"은 라이브 성격이라 덱, "기간 종합 요약"은 리포트 성격이라 리서치 페이지.

## 각 Phase는 자체 스펙→계획→구현 사이클을 가진다. 이 문서는 상위 로드맵이며, Phase별 상세 설계는 별도 스펙으로 작성한다.
