## 참고: 리포트와 대시보드의 데이터 처리 차이 (같은 원데이터 trend_view)
- 같은 점: 검색량 = 묶음 전체 합(이름+수식어+연관+한국 조합, 제외·노이즈 뺌), 최근 3개월 vs 1년 전 같은 3개월.
- 리포트가 의도적으로 다르게 한 것: 피부과 시술 201개만 / 뜨는·줄어든 시술은 월 1만 이상 / 대표 판정은 1년 변화(대시보드는 계절 보정 최근 3v3 흐름) / 늘어난 검색 수 순 정렬 / 동음이의 28개 통째 제외.
- **의도치 않은 차이**: 다른 진료과 혼재 시술(`serp.med >= MED_MIX(8)`)을 대시보드는 `noName`으로 세는데 리포트 `analyze.py`는 `total`을 씀 → PRP 12,050(리포트) vs 643(대시보드). 발행본엔 미노출. 리포트 쪽 수정 과제(이 워크트리 범위 아님).
