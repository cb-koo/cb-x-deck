상태 전송(POST)할 때 `external_id`도 함께 보내주실 수 있을까요?

*무엇을*
• `POST /api/external/settlement/requests/{request_id}/status` 본문에 `external_id` 한 줄 추가
• 값은 그쪽 시스템에서 그 정산 건을 가리키는 번호(형식 자유, 최대 100자)
• 이미 명세에 있는 **선택 항목**이라 계약 변경은 없습니다 — 지금도 보내주시면 저장됩니다

*왜*
지금은 저희가 그쪽 건을 부를 방법이 저희 쪽 요청 번호(36자 uuid)뿐입니다.
예: `f65553e4-8c26-47c8-a6cf-3cbab28541e3`
어제 금액 문의를 맞춰볼 때도 이 uuid를 그대로 주고받아야 했습니다. 그쪽 번호가 함께 오면 양쪽이 같은 번호로 부를 수 있어서, 문의·대조가 훨씬 빨라집니다. 저희 화면에도 그 번호를 띄워 두겠습니다.

*예시*
```
POST /api/external/settlement/requests/f65553e4-8c26-47c8-a6cf-3cbab28541e3/status
{
  "status": "paid",
  "updated_at": "2026-09-01T11:02:03.189Z",
  "paid_amount_krw": 31650,
  "paid_at": "2026-09-01T10:59:00Z",
  "external_id": "PAY-2026-0901-007"
}
```

*이미 처리한 건은 소급하지 않아도 됩니다*
새로 보내는 건부터 채워주시면 충분합니다. 굳이 기존 건에 번호만 채우고 싶으시면, 같은 내용에 `external_id`만 더해 다시 보내주시면 됩니다(`paid → paid` 정정은 허용됩니다). 이때 `updated_at`은 **새 시각**으로 찍어주세요 — 이전 값이면 오래된 변경으로 보고 무시합니다(`applied: false`, `reason: "stale"`).
