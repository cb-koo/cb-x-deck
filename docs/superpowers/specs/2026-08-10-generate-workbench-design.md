# /generate 워크벤치 개편 설계 (2026-08-10)

## 배경과 목표

`/generate`는 X 원고 초안을 만드는 페이지인데, 현재는 600px 단일 컬럼 피드형이다(컴포저 위 + 결과 카드가 아래로 쌓임). 실사용자는 하루에 여러 번 조건을 바꿔가며 생성을 반복하고 쌓인 초안을 검수·확정·전달하는데, 이 레이아웃에서는:

1. 결과를 검토하다 조건을 바꾸려면 매번 맨 위로 스크롤해야 한다 (반복 루프 마찰)
2. 생성 옵션이 '바꾸기' 뒤에 접혀 있어, 직전 설정이 localStorage로 유지된 상태에서 어떤 조건으로 생성되는지 안 보인 채 비용 유발 버튼을 누르게 된다
3. 상태 필터 탭·클라이언트 필터가 본문 텍스트와 시각 위계가 겹쳐 묻힌다

리서치(`~/claude-outputs/20260810-generate-page-uiux-research.md`)로 확인한 관례: 생성이 주 작업인 도구는 "좌=조건 / 우=결과" 2단이 표준(Jasper·Copy.ai·ChatGPT Canvas), 비용·형식 파라미터는 기본 노출 + 생성 버튼 옆 조건·비용 요약(ShapeofAI), 상태 필터는 탭+건수 배지를 콘텐츠와 대비되는 불투명 배경으로 물리 구획(NN/g·Grafana·Buffer).

**목표**: 피드형 페이지를 "좌 생성 패널 / 우 결과"의 2단 워크벤치로 재구성해, 조건이 항상 보이는 상태에서 생성↔검토 루프가 스크롤 없이 돌게 한다. 서버·API 변경 없음(순수 프론트엔드).

## 확정된 결정 (브레인스토밍 시안 검토 결과)

- **B안 — 2단 워크벤치**: 좌 생성 패널(기본 300px) / 우 결과 영역, 두 컬럼 독립 스크롤
- **B-2 — 조건 먼저**: 좌패널 내부 순서는 폼(조건) → 레퍼런스 → 방향성 → 고급 옵션 → 하단 고정 요약+버튼
- **클라이언트 컨텍스트 칩 제거**: 클라이언트 셀렉트가 폼 첫 필드로서 컨텍스트 표시를 겸한다(중복·거짓 어포던스 방지). 우측 헤더의 클라이언트 필터는 별개(결과를 거르는 렌즈)로 유지하되 "모든 클라이언트"처럼 필터임이 드러나는 라벨을 쓴다
- **좌패널 리사이즈 포함**: 구분선 드래그 260~480px, 더블클릭 시 기본 폭 복원, localStorage 저장. 완전 접기(아이콘 레일)는 이번 범위 제외 — 실사용 마찰 확인 후 승격 검토 (AGENTS.md 원칙 6)
- **공통 확정 4건**: 하단 고정 요약+생성 버튼 / 시안 수·방향성은 생성 후 초기화되는 현행 정책 유지 / '생성 제약'만 고급 옵션으로 접힘 / 좁은 화면은 상하 스택 폴백

## 레이아웃 구조

```
GlobalShell (flex h-screen)
└─ 콘텐츠 래퍼 (min-w-0 flex-1 overflow-y-auto)   ← 기존 그대로
   └─ GeneratePage 루트: h-full flex  ← 페이지가 자체 2단을 관리, 래퍼는 스크롤 안 함
      ├─ 좌: 생성 패널 (기본 w-[300px], 260~480 리사이즈)
      │   ├─ 스크롤 영역 (flex-1 overflow-y-auto)
      │   │   ├─ 페이지 제목 "콘텐츠 생성" + 한 줄 설명 (컴팩트, h1 유지)
      │   │   ├─ (클라이언트 0건일 때) 등록 유도 배너
      │   │   ├─ ① 생성 조건 폼: 클라이언트 셀렉트(첫 필드) · 시술 칩 · 형식 · 참고 방식 · 시안 수 — 항상 펼침
      │   │   ├─ ② 레퍼런스: 연결된 트윗 칩 + "보관함에서 고르기"
      │   │   ├─ ③ 방향성 textarea (자유 서술 — 폼과 시각 구획 분리)
      │   │   └─ ④ "고급 옵션" 접힘 (생성 제약 토글)
      │   └─ ⑤ 하단 고정 풋터 (border-t, 스크롤 밖): 조건+비용 요약 한 줄 + [원고 만들기] 전폭 버튼
      ├─ 구분선: 드래그 리사이즈 핸들 (hover 시 굵어짐 + col-resize 커서)
      └─ 우: 결과 영역 (min-w-0 flex-1 flex-col)
          ├─ ⑥ 필터 헤더 (스크롤 밖 고정 행, bg-x-surface 불투명 + border-b):
          │     상태 탭+건수 배지 (전체/초안/검수 대기/사용 확정/전달됨/미사용) + "모든 클라이언트 ▾" 필터
          └─ ⑦ 카드 스크롤 영역 (flex-1 overflow-y-auto):
                생성 중 스켈레톤(최상단) → 초안 카드들(max-w-600 중앙 정렬) → 빈 상태 안내
```

- 필터 헤더는 sticky가 아니라 **스크롤 컨테이너 밖의 고정 행**으로 구현한다(Dense Scan List 패턴). 효과는 스티키와 같고 z-index·불투명 배경 처리가 단순해진다. 카드 영역과 배경 대비(x-surface vs white 카드)로 구획.
- 시각 층 원칙 유지: 좌패널·필터 헤더는 도구층(Reading 스케일·x-surface), 우측 초안 카드는 X 콘텐츠층(X 실측 스케일) 그대로.

## 컴포넌트 변경

### `src/app/generate/page.tsx` — 골격 재배치
- 루트를 `h-full flex`로 바꾸고 위 구조대로 재배치. 상태·핸들러 로직(generate/rewrite/폴링/삭제 실행취소/무시 표식/상태 변경)은 **변경 없음** — 이동만 한다.
- 스켈레톤·빈 상태 2종("아직 초안이 없어요", "이 조건에 맞는 초안이 없어요")·토스트·DraftEditModal·RefPickerSheet는 기존 그대로, 렌더 위치만 우측 카드 영역/오버레이로.
- 리사이즈 상태: `cbx-composer-width` localStorage 키. 드래그 중 텍스트 선택 방지(`select-none`), 더블클릭 시 300px 복원. 저장값이 범위 밖이면 클램프해서 복원.

### `src/components/DraftComposer.tsx` — 세로 패널로 개편 (가장 큰 변경)
- `open` 접힘 상태 제거 — 조건 폼은 항상 펼침. 요약 텍스트 줄(`summary`)은 접힘용이었으므로 제거하고, 그 역할은 하단 풋터의 요약줄이 승계.
- 섹션 구성 (ClientDetail 관례의 카드 섹션 — 테두리+제목 헤더):
  - **생성 조건**: 클라이언트 셀렉트(첫 필드, 0건이면 "클라이언트를 먼저 등록하세요 →" 링크), 시술 칩 토글, 형식(단문/스레드), 참고 방식(형식만/앵글만/형식+앵글), 시안 수(1~5)
  - **참고 방식 행은 레퍼런스가 없으면 비활성** + "레퍼런스를 연결하면 선택할 수 있어요" 캡션 — 현재는 레퍼런스 없이도 눌리지만 생성 시 'off'로 무시되므로, 라벨과 값 불일치(원칙 4)를 비활성으로 해소. 전송 로직(`mode: refRows.length > 0 ? mode : 'off'`)은 그대로.
  - **레퍼런스**: 연결 칩(✕ 제거)·모두 빼기·"+ 보관함에서 고르기" — 현행 기능 그대로, 위치만 상단 바에서 섹션으로
  - **방향성**: textarea 3줄, 기존 라벨·placeholder 유지
  - **고급 옵션** (접힘, 기본 닫힘): 생성 제약 토글 + 기존 설명문
- **하단 고정 풋터**: 파생 요약 "선한의원 · 리프팅 · 단문 · 시안 1개 → 약 $0.02 · 15~30초" (모든 값이 composer 상태에서 파생 — 원칙 4). 생성 불가 시 기존 안내문("클라이언트·레퍼런스·방향성 중 하나는 있어야…"), 생성 중엔 [취소] 버튼 + "취소해도 완성되면 목록에 저장" 캡션. 시안 수 >1이면 비용 ×N 표기 유지.
- `ComposerState`·`DEFAULT_COMPOSER`·localStorage 정책(방향성·시안 수는 저장 안 함) 변경 없음.

### `src/components/DraftFilterBar.tsx` — 위치·표면만 변경
- 탭+건수, 클라이언트 셀렉트 로직 그대로. 우측 헤더 행에 맞는 스타일(패딩·배경은 부모가 담당)로 조정하고, 셀렉트 기본 옵션 라벨을 "모든 클라이언트"로 유지(현행과 동일). 필터는 세션용 렌즈라 저장하지 않는 정책 유지.

### `src/components/DraftCard.tsx` — 상태 스트립 상단 이동 (소규모)
- 회색 도구층 풋터의 첫 행(DraftStatusChip + 시안 라벨)을 **카드 상단의 회색 도구층 스트립**으로 이동하고, 메타 "시술명 · 단문/스레드"를 덧붙인다 — 카드를 스크롤 없이 훑어도 상태·조건이 좌상단 동일 위치에서 읽히게(리뷰 큐 트리아지 관례).
- 시간은 흰색 X층 헤더("멤버명 · 초안 · n시간 전")에 이미 있으므로 스트립에 중복 표기하지 않는다. 검수 표식·PR 안내·근거 풋터는 하단 회색층에 그대로 — 층 원칙(흰=X 미러 / 회색=도구층) 불변.

## 경계 조건

- **좁은 화면 폴백**: `lg`(1024px) 미만에서는 상하 스택 — 좌패널이 자연 높이 블록으로 위(내부 스크롤 없음, 풋터도 일반 흐름), 필터+카드가 아래, 페이지 전체 스크롤(현행과 동일한 동작). 리사이즈 핸들 숨김.
- **리사이즈 상한 동적 클램프**: 우측 카드 영역이 최소 480px을 확보 못 하는 창 폭에서는 드래그 상한을 `컨테이너 폭 - 480`으로 낮춘다(카드가 뭉개지는 것 방지). 계산 결과가 하한(260px)보다 작아지는 창 폭이면 이미 스택 폴백 구간이다.
- **생성 중 이탈/취소**: 취소 → 폴링 자동 반영(스펙 3-5) 로직 무변경. 스켈레톤 문구(시안 N개 안내) 무변경.
- **`/generate?ref=` 진입점**: 무변경 — 연결 결과가 좌패널 레퍼런스 섹션에 나타난다.
- **필터에 가려진 새 초안 자동 노출**(T11): 무변경.

## 접근성

- 리사이즈 핸들: `role="separator"` + `aria-orientation="vertical"` + `aria-label="패널 폭 조절"`, 키보드 화살표로 16px 단위 조절(포커스 가능). 더블클릭 복원은 마우스 전용 보조 수단.
- 상태 탭 건수는 현행 텍스트 그대로(스크린리더가 "검수 대기 12"로 읽음). 제목 h1 유지.

## 검증

- 컴포넌트 하네스가 없으므로: `npx tsc --noEmit` + lint(기준선 24개 초과 금지) + 기존 `npm test`(생성 프롬프트 검증 등)가 깨지지 않는지 확인. 로직 이동이 전부이고 신규 로직은 리사이즈 클램프뿐이므로, 클램프 함수는 순수 함수로 분리해 tsx 단위 테스트 1건 추가(`draftUi` 테스트 관례).
- 화면 확인은 OAuth 게이팅으로 사용자만 가능 — 배포 전 dev 서버에서 사용자 검수(넓은 창/좁은 창/리사이즈/생성 흐름).
