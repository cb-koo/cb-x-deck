# 덱 페이지 UI/UX 정돈 — 설계 (2026-07-19)

## 배경·목표

기능은 완성됐지만 타이포그래피·정보 위계·디자인 구성이 혼잡하다는 사용자 피드백에서 출발.
목표: **기능·API·저장 데이터 완전 불변**의 표시 전용 정돈 + 경량 디자인 시스템(토큰·공용 컴포넌트) 확립.

사용자 확정 사항:
- 방향 = **X 은유 유지 + 정돈** (X.com 라이트모드 미러링은 강점이므로 유지, 정돈만)
- 시스템 수준 = **경량 자체 시스템** (CSS 토큰 + 공용 컴포넌트, 외부 라이브러리 도입 없음)
- 적용 폭 = **A안: 토큰+위계+구획 전체** (기능·레이아웃 구조는 불변)
- 카드 기능층 = **B1: 덱 풋터 존** + 팔로워는 아이브로(계정 아이디 위 캡션)
- 시안: `~/claude-outputs/cb-x-deck-덱-UI정돈-시안-20260719.html` (v6 확정)

## 진단 (혼잡함의 4가지 뿌리)

1. 글자 크기 6단계(10~15px 임의 px)가 중요도와 무관하게 혼재, 볼드 남발로 강조 위계 소실
2. 모든 구획이 동일한 1px border — 패널을 열면 도구/콘텐츠 경계가 사라짐
3. 컨트롤 중요도 구분 없음 (매일 쓰는 정렬과 가끔 쓰는 버림 보기가 동급 나열)
4. 토큰이 색상만 존재, 버튼 스타일 4종이 3개 파일에 문자열 상수로 중복, 이모지/SVG 아이콘 혼용

## 리서치 근거 (exa, 2026-07-19)

- **X 원본 스케일**: 11/13/15/20px + 무게 400/500/700만 사용 — 현재 덱이 원본보다 복잡함
- **밀집 대시보드 공통 규칙**: 크기=중요도, 무게=종류, 색=상태. 크기 3~4단계 제한, 숫자는 tabular + 우측 정렬
- **TweetDeck**: 무채색 기조 + 강조색은 신규 신호에만
- **Sprout Seeds 디자인 시스템**: 레이아웃 존 분리(도구/콘텐츠), **Message.Footer** 패턴(소셜 콘텐츠 카드 아래 구분된 풋터에 도구 액션·데이터)
- **소셜리스닝 리디자인 사례**: 저빈도 필터 과다 노출이 혼잡의 주범, 활성 필터는 피드 위에 명시
- **Tailwind v4 @theme**: 현 x-* 색 토큰 방식이 권장 구조 — 타이포·컴포넌트로 확장

## 설계

### §1 타이포그래피 토큰 (X 스케일 회귀)

`globals.css @theme`에 역할 토큰 4단계. 덱의 모든 텍스트는 이 토큰만 사용(임의 px 금지):

| 역할 | 크기/무게 | 쓰는 곳 |
|---|---|---|
| content | 15px/400 | 트윗 본문 (X 미러링, 현행 유지) |
| content-strong | 15px/700 | 작성자명, 컬럼 제목 |
| ui | 13px/400 | 도구 영역 전부 (정렬 탭·버튼·패널 본문) |
| caption | 11px/400 | 메타데이터 (팔로워·수집일·근거 줄·패널 설명) |

볼드 규율: **700 = 아이덴티티(제목·작성자명)만**, 500 = 활성 상태·판정문, 400 = 나머지.
숫자: 수치 표시 요소에 `tabular-nums`, 패널 수치는 우측 정렬.

### §2 표면 2층 구조

새 토큰 `--color-x-surface`(#f7f9f9 계열). **회색 = 덱의 도구층, 흰색 = X 콘텐츠**가 앱 전체 문법:
- 도구 존(회색): 컬럼 헤더, 추이·주제 분석 패널, 해시태그 스트립, 사이드바, 카드 풋터
- 콘텐츠 존(흰색): 트윗 목록·카드

### §3 컨트롤 3단 위계 (컬럼 헤더, 기능 불변)

- 1차 — 정렬 4종: 세그먼트 탭 (활성 = 500 무게 + 파란 밑줄, X 은유)
- 2차 — 분석 토글 (추이·주제 분석): ghost 칩, 활성 = 흰 배경 + 테두리
- 3차 — 보기 상태: 버튼 3개 나열 → 드롭다운 `보기: 전체 ▾` (전체/NEW만/버림, 실사용상 상호배타)

### §4 강조색 규율

x-blue 사용처 3가지로 한정: ① 링크·주요 액션 버튼(비용 액션 등 1개) ② 신규 신호(NEW 배지·진행 바) ③ 활성 탭 밑줄. 토글 활성을 볼드+파랑으로 표시하던 것 등은 제거.

### §5 공용 컴포넌트 + 아이콘 (경량 시스템의 몸통)

- `Button`: primary / subtle / ghost / icon 4변형 — btn·iconBtn·smallBtn·primaryBtn 문자열 상수 중복 제거
- `PanelShell`: 분석 패널 공통 골격(제목 500 + 설명 캡션 + 닫기, surface 배경) — Trend/Pillar/Cooccurrence 공유
- 도구 영역 이모지(🔍👤, 사이드바 🔍📊📋📁) → XIcons SVG 추가·교체. 콘텐츠 의미 배지(⚠️薬機法)는 유지

### §6 활성 필터 가시화

주제 필터·NEW만·버림 상태 시 트윗 목록 최상단에 상태 칩: `주제: 클리닉·의료진 정보 ✕` + "N건 표시 중" 힌트. ✕로 해제. 패널을 닫아도 필터 상태가 보임.

### §7 트윗 카드 — 덱 풋터 존 (Sprout Message.Footer 패턴)

카드 구조(위→아래):
```
[흰색 — X 원본 + 계정 컨텍스트]
  팔로워 4,213                       ← 아이브로: 11px 캡션, 이름 줄 위 (계정 규모 → 누구 → 내용)
  이름(15/700) @핸들 · 날짜(15/400 secondary)
  본문 / 미디어 / 인용 카드 / 지표 바  ← X 원본 그대로
[회색 풋터 — 덱 기능층]
  답글⌄ 스레드⌄ 리포스터⌄ (탐색·비용, 좌) | ☆ 저장 · ✕ 버림 (판단, 우)   ← ui 토큰(13px) 칩 버튼, 호버 배경 (시안의 12px는 토큰 준수로 13px 통일)
  수집 7/7 · 갱신 7/18 (11px, 우측 정렬)   ← 시스템 메타, 최저 무게
```
- 팔로워 배지(회색 박스) 폐지 — 박스는 버튼/태그로 오인됨. 근접 원칙: 부가 데이터는 설명하는 대상(계정) 옆에
- 저장됨 상태: 멤버 점 + ★(amber) 라벨이 저장 버튼과 한 몸 (`박 ★ 저장됨`)
- 탐색 3종은 ⌄ 펼침 어포던스(브리핑 '원본 보기 ⌄'와 동일 은유), 비용 툴팁($0.001) 유지
- TweetExpansion 펼침 영역도 surface 토큰으로 통일

**정제된 원칙**: 부가 데이터는 설명하는 대상 옆에(캡션 무게), 액션·시스템 메타는 풋터 존에.
