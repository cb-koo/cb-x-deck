# /generate 원고 제목(한국어 라벨) 설계 (2026-08-10, 워크벤치 5차)

## 배경

테이블·칸반의 항목 라벨이 "본문 첫 줄"인데, X 원고는 제목이 없고 훅 문장은 서로 비슷해 식별자 역할을 못 한다. 검토한 대안(A 방향성 라벨 / D 주제 필드 / E 자동 제목) 중 **완전 E안 확정**: 모든 항목의 라벨 의미가 "내용 요약"으로 통일되고, 다중 시안이 자연히 구별되며, 향후 D안(주제)과 "주제=그룹 축, 제목=항목 이름"으로 역할이 나뉜다.

## 제목 생성 원칙 (검색·분류 대비 — 사용자 질문 1 반영)

1. **필드 중복 금지**: 클라이언트·시술·형식·상태는 구조화 필드로 존재 — 제목은 필드에 없는 "이 원고만의 앵글·소구점"을 담는다(예: "다운타임 3일 후기형", "가격 비교로 불안 해소").
2. **15자 내외 한국어 명사구**, 이모지·해시태그·괄호 장식·마침표 금지(검색 노이즈), 문체 통일(향후 임베딩·군집 품질).
3. **용어집(GLOSSARY) 우선 적용** — 표기 흔들림 방지.
4. **버전 안정성**: 같은 버전=같은 제목(캐시), 편집으로 원고가 바뀌면 해시 불일치로 자동 무효(낡은 제목이 검색을 오염시키지 않음).
5. 분류 체계는 제목이 아니라 향후 주제 필드(D안) 소관 — 제목은 표시명+검색 보조로 한정.
6. **일본어 제목은 생성하지 않음**(사용자 질문 2) — 소비자가 한국인 팀이고, 일본어 검색은 본문 원문이 커버. 필요 시 additive로 추가 가능.

## 핵심 설계

### 생성: 기존 대역 호출에 제목을 동승 (추가 호출 없음)
`translateDraftPosts`를 확장해 같은 haiku 호출이 번역과 함께 **제목 1개**를 출력: 반환형 `{ posts: string[]; title: string | null } | null`. 제목 규칙(위 1~3)을 프롬프트에 명시. title 키가 없거나 비면 title=null(번역만 저장 — 제목은 부가물의 부가물).

호출 경로 3+1곳 모두 제목을 저장:
- generateDraft(시안별)·rewriteDraft·regeneratePost — 4차 대역 경로에 title 저장 동승
- **translate 라우트(번역 보기 버튼)** — 과거 원고도 버튼 한 번이면 제목이 소급 생성됨(폴백 체인이 자연히 채워짐)

### 저장: draft에 컬럼 2개 (마이그레이션 016 — 이 프로젝트 첫 스키마 변경)
```sql
alter table draft add column ko_title text, add column ko_title_hash text;
```
- `ko_title_hash` = 제목이 만들어진 버전의 `draftVersionHash` — toRow가 최신 버전 해시와 대조해 일치할 때만 `koTitle: string | null`로 노출(스테일 방지, koLatest와 동일 패턴).
- nullable·기본 null이라 배포 순서 안전(구버전 코드와 공존 가능). `insertDraft`·`updateDraft`에 koTitle/koTitleHash 입력 추가.

### 표시: 폴백 체인 확정
`draftLabel(d)`: **koTitle → 🌐+한국어 첫 줄(draftKoLine) → 원문 첫 줄(draftPreviewLine) → '(내용 없음)'**
- 제목에는 🌐를 붙이지 않는다 — 🌐는 "본문의 번역" 표지이고 제목은 생성 라벨(라벨-값 일치). sr-only도 불필요.
- **칸반 카드**: 제목이 있으면 제목(text-ui, font-medium) + 아래 본문 미리보기(대역 우선, 1줄, caption·muted)로 강등. 제목이 없으면 현행 그대로(첫 줄 2줄).
- **테이블 '원고' 셀**: 라벨 1줄(truncate). 제목일 때 title 속성으로 본문 첫 줄 노출(호버 보조).
- 다중 시안 라벨("시안 A · 같은 조건 N개 중")은 카드 상단 스트립 현행 유지 — 제목과 역할 분리.

## 경계 조건

- 과거 원고: koTitle 없음 → 폴백 체인으로 현행과 동일하게 보임. 번역 버튼·다시 쓰기를 거치면 제목 생성.
- 제목 생성 실패·누락: 번역만 저장(대역 인프라의 침묵+warn 계약 그대로). 번역 실패 시엔 둘 다 없음.
- rewrite·regen의 캐시 선조회(4차 F3)로 번역을 건너뛴 경우: 제목도 재생성 기회가 없음 — `ko_title_hash`가 이미 새 버전과 일치하면 그대로 두고, 불일치인데 번역 캐시만 있으면 제목 없이 진행(폴백 표시). 허용 — 희귀 경로에 별도 호출을 만들지 않는다(YAGNI).
- **이미 번역 캐시가 있는 과거 원고**: translate 라우트가 캐시 히트로 조기 반환하므로 버튼을 눌러도 제목이 안 생긴다 — 폴백(🌐 대역 첫 줄)이 이미 충분히 읽히므로 허용(YAGNI). 이런 원고도 다시 쓰기를 거치면 제목이 생긴다.
- 4차와 동일: 타임아웃 15초·mock client 전달·사용량 채널 `anthropic.draftTranslate` 그대로.

## 검증

- translateDraftPosts 확장의 단위 테스트(제목 파싱·누락 시 null) + generate.test에 제목 저장·koTitle 노출·편집 무효화 검증 추가. 기존 테스트는 반환형 변경에 따른 **호출부 수정만**(assertion 의도 불변).
- 마이그레이션은 `npm run migrate`로 적용(기존 015 관례). tsc 0·lint 24·전체 회귀.
