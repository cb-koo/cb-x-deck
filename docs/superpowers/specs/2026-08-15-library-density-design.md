# 보관함 카드 밀도 개선 — 편차 축소 + items-start (2026-08-15)

## 배경 / 문제

보관함(`/w/[wsId]/library`)은 3열 균등 그리드(`grid-cols-1 md:grid-cols-2 xl:grid-cols-3`)에 CandidateCard를 얹는데, 카드 높이에 상한이 없고 그리드 기본값(stretch)이 적용된다. 한 행에 긴 카드(긴 본문·큰 이미지·인용·코멘트 다수)가 하나만 있어도 옆 짧은 카드의 테두리 박스가 그 높이까지 늘어나 안쪽에 빈 공간이 생긴다.

### Masonry 반려 근거 (검토 후 폐기)

- 카드가 정적이지 않음: 코멘트 인라인 편집·확인창·번역 토글이 높이를 바꾸며, masonry는 그때마다 전체를 재배치해 편집 중인 카드가 튄다. 인라인 코멘트("코멘트 달기 = 저장으로 계산")는 팀 참여 장치라 팝업으로 밀어낼 수 없음.
- 최신 저장순 정렬과 충돌: 행 단위 스캔("이번 주 팀이 담은 것")이 깨짐.
- 네이티브 CSS masonry 미성숙 + JS 라이브러리·ResizeObserver 비용 대비 이득 부족.
- 재검토 조건: 보관함이 이미지 중심 무드보드로 성격이 바뀌면 그때 다시 논의.

## 결정

카드 높이 **편차 자체를 줄이고**(각 가변 요소에 상한 + 클릭 펼침), 그리드에 **items-start**를 적용해 강제 스트레칭을 없앤다. 시안(아티팩트 "보관함 카드 시안") 사용자 승인 완료.

## 변경 사항 (보관함 한정 — 덱·generate는 무변경)

1. **items-start**: library 페이지 `<main>` 그리드에 `items-start` 추가. 카드가 내용 높이만큼만 그려짐.
2. **본문 6줄 클램프 + "더 보기"**:
   - `line-clamp-6` 상당. 원문과 번역 박스 본문 모두 동일 규칙.
   - **실제로 잘렸을 때만** 표시(거짓 어포던스 금지): ref로 `scrollHeight > clientHeight` 측정. 번역 토글 등 내용 변화 시 재측정.
   - **가시성 규칙(사용자 요구)**: 잘린 끝 줄 위에 흰색 페이드아웃 그라데이션 + "더 보기 ▾"는 파란 틴트 배경(`bg-x-blue/10`, `text-x-blue-text`) 알약 버튼. 누르면 그 자리에서 펼쳐지고 "접기 ▴"로 바뀜.
3. **단일 이미지 세로 상한**: MediaGrid 단일 이미지 `max-h-96`(384px) → 보관함에서는 208px 안팎(`max-h-52`). opt-in prop으로 전달해 덱 기본값은 유지. 2장 이상(정사각 그리드)은 현행 유지.
4. **인용 트윗 접기**: QuotedCard를 보관함에서는 본문 2줄 클램프 + "▾ 눌러서 펼치기" 힌트로 접는다. opt-in prop.
   - 기존 동작과의 충돌 해결: QuotedCard는 이미 박스 전체 클릭 = 인용 원문 새 탭 열기다. **접힌 상태에선 박스 클릭 = 펼침**(원문 열기 아님 — 첫 클릭이 안전), **펼친 뒤엔 박스 클릭 = 원문 열기(기존 동작) + 별도 "▴ 접기" 컨트롤**(stopPropagation). 인용 미디어는 펼친 상태에서만 표시.
5. **코멘트 접기**: CandidateCard에서 코멘트가 2개 이상이면 최신 1개(savedAt 기준)만 표시 + "코멘트 N개 더 보기" 토글. 펼치면 전체가 보이고 내 코멘트 수정·제거도 그때 접근. 인라인 코멘트 입력창은 항상 유지.

## 구현 위치와 경계

- `src/app/w/[wsId]/library/page.tsx`: 그리드 `items-start`.
- `src/components/TweetCard.tsx`: `clampBody?: boolean`(가칭) opt-in prop — 기본 false라 덱·generate·모달 무영향. 클램프·측정·더 보기 버튼은 이 컴포넌트 안.
- `src/components/MediaGrid.tsx`: 단일 이미지 높이 상한 prop.
- `src/components/QuotedCard.tsx`: 접기 opt-in prop (TweetCard가 전달).
- `src/components/CandidateCard.tsx`: 코멘트 접기 + prop 배선.
- 펼침 상태는 카드별 로컬 state. 목록 재로드 시 접힘으로 초기화되는 것 허용.

## 엣지 케이스

- 코멘트 1개면 접기 UI 없이 현행 그대로.
- 본문이 6줄 이하면 페이드·버튼 모두 미표시.
- 클램프 상태에서 전체 번역을 켜면 번역 박스도 각자 클램프·측정.
- 삭제 확인창·실행취소 흐름은 무변경.

## 검증

- `npm run lint`(기준선 24건 초과 금지) + `npm run build`.
- 컴포넌트 하네스 없음 → 화면 확인은 로컬 `build + start -p 3001 + 127.0.0.1` 후 koo QA (OAuth 게이팅).
- 확인 항목: ①~⑤ 각 동작, 더 보기 가시성(페이드+알약), 잘리지 않은 카드에 버튼 없음, 덱·generate·트윗 모달의 카드가 기존과 동일함.
