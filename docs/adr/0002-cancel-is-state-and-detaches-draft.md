# 취소는 삭제가 아니라 상태이고, 붙어 있던 원고를 자동으로 뗀다

거절·무응답으로 진행하지 않게 된 작업을 지우면 "왜 @c가 없지?"가 되고 캠페인에서 무슨 일이 있었는지 사라진다. 취소는 `campaign_task`에 **취소일·사유(선택)** 로 남기고, 화면에서는 접힌 "취소" 섹션에 두며 비용 합계·게시 n/N·밀림에서 뺀다(미사용 원고 작업을 합계에서 빼는 기존 규칙과 같은 결). 되돌리기는 허용한다.

원고는 작업 1개에만 붙을 수 있으므로(unique index), 취소된 작업이 원고를 물고 있으면 그 원고를 다른 인플루언서에게 줄 수 없다. 거절 → 같은 원고를 다음 사람에게 주는 것이 실무라 **취소 시 원고를 자동으로 떼어** 재사용 가능하게 한다. 취소 행에는 "원고 있었음: 제목"만 회색으로 남긴다. 되돌릴 때 원고가 아직 비어 있으면 다시 붙이고, 이미 다른 작업에 갔으면 그 사실을 안내한다.

## Consequences

- 취소는 **게시 전에만** 가능하다. 게시 뒤 게시물이 사라진 것은 기존 "내림"(removed_at)이며 정산 참고 정보다 — 두 개념을 섞지 않는다.
- 사유 값은 DB에 영어(`declined` / `no_response` / `other`), 화면은 슬랙 관례를 따르는 이모지+단어 칩. 메모 한 줄은 자유 텍스트, 둘 다 선택 입력.
