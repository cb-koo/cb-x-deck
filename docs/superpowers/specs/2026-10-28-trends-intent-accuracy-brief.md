# 검색 트렌드(/trends) 검색 의도 비중 정확도 — 작업 브리프 (2026-10-28)

이 워크트리(`cb-koo/trends-intent-accuracy`) 전용 작업. **아직 시작 전.** koo가 이 워크트리에서 요청하면 시작한다.
배경: b2b-marketing 세션(10-28, `f965c3cd`)에서 쥬베룩(바임 미팅)·써마지(솔타메디칼 미팅) 검색 의도 PDF를 만들다가, 대시보드·웹 리포트의 의도 비중이 왜곡돼 있음을 발견. koo가 "웹 리포트·대시보드 개선은 별도 작업"으로 미뤄 둔 것을 여기서 한다.
분류 체계 교체(`cb-koo/trends-taxonomy`)와는 축이 다르다 — 그쪽은 '어느 분류에 넣나', 이쪽은 '의도 비중 숫자가 맞나'.

## 발견한 문제 4가지

### 1. 정해 둔 검색어 틀만 세서 의도 비중이 쏠림 (가장 큼, 비용 있음)
대시보드는 시술명 + 정해 둔 말(효과·불안·가격·지역·한국·정보 6종) 검색어만 센다. 틀에 칸이 없는 시술 방식·고민 부위·비교 검색은 집계되지 않는다.

| 쥬베룩 | 대시보드·웹 리포트 (53개) | 보정 PDF (실제 검색어 234개) |
|---|---|---|
| 의도가 드러난 검색 | 12,936 | 34,118 (2.6배) |
| 효과 확인 | 42.2% | 21.1% |
| 불안 | 28.0% (3,620) | 27.5% (9,383) |
| 시술 방식·부위·비교 | 0 (칸 없음) | 29.0% |

- 빠진 큰 검색어: 「危険性」 2,017 · 「手打ち」 1,708 · 「水光注射」 1,150 · 「リジュラン 違い」.
- 보정 방법: 일본 Google 자동완성(SerpAPI) + 검색 결과 연관 검색어 + 기존 검색어 → 키워드 플래너 검색량 조회. 키워드 플래너 `generateKeywordIdeas`는 의료 시드에서 자기 자신만 돌려줘 못 쓴다.
- 시술 201개 전체에 하면 SerpAPI 사용량이 크다 → **상위 시술 몇 개로 쏠림 정도부터 확인** 권장.

### 2. 띄어쓰기 이상값 (비용 없음)
키워드 플래너가 붙여 쓴 「〇〇とは」에 큰 값을 준다.
- 쥬베룩: ジュベルックとは 8,500 vs ジュベルック とは 171 (50배)
- 써마지: サーマクールとは 1,658 vs サーマクール とは 37 (46배)
- 대시보드 써마지 '정보' 30.6%(1위)는 대부분 이 값 → 써마지 '알아보는 중(탐색)' 단계 판정 자체가 오류일 가능성.
- 리포트 쪽 처리: 붙여 쓴 쪽 제외. 대시보드 `src/lib/searchIntent.ts` `norm()`은 공백 제거로 매칭만 하고 이상값 처리는 없다.

### 3. 같은 검색량 이중 집계 (비용 없음, 원인 재현 먼저)
어순·조사만 다른 검색어에 같은 값(「サーマクール 効果」 = 「サーマクール の 効果」 = 926~927). 써마지에서 22건 합침(같은 단어 조합 + 48개월 값 동일).
- **주의:** 대시보드엔 이미 `dedupe()`(`searchIntent.ts`, 48개월 완전 동일 시 하나만, 월평균 50 미만은 건드리지 않음)가 있다. 왜 안 걸렸는지 미확인 — 한두 달 값이 다름 / 웹 리포트(`analyze.py`) 쪽 문제 / 50 미만 예외 중 무엇인지 운영 데이터로 먼저 재현.

### 4. 써마지 세대·부위 혼재 (분류 체계 작업과 겹침)
FLX·CPT = 본체 세대, 아이·바디 = 같은 장비의 부위별 팁. 써마지 아이 검색 2,768회 중 세대를 함께 쓴 검색 0건. 분류 체계 워크트리에서 마스터 적용 시 함께 정리.
