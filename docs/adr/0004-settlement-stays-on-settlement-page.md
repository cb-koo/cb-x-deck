# "한 화면에서 전체 플로우"의 예외 — 정산 요청(⑧)은 정산 페이지에 남긴다

캠페인 v2의 방향은 ①캠페인 생성부터 ⑧정산 요청까지 한 화면에서 처리하는 것이지만, 정산 요청 생성에는 분류·환율·수수료·마감일·신호등 검토가 붙어 있고 그 화면(`/settlement`)이 이미 그쪽 정산 프로덕트와의 계약을 진다. 이번에는 캠페인 v2가 **완료된 작업 수와 정산 페이지 링크(캠페인 미리 선택)** 까지만 제공하고, 요청 생성은 정산 페이지에서 한다. 통합은 이 화면이 자리 잡은 뒤 다시 본다.

## Consequences

- 정산 페이지 검토 대기 탭이 `?tab=candidates&campaign=` 파라미터로 캠페인 필터 초기값을 받게 한다(정산 로직·연동 무변경, 필터 초기값만).
- 정산 상태 배지(대기·요청됨·지급 완료)는 기존 작업 배지를 완료 섹션에 그대로 쓴다.
