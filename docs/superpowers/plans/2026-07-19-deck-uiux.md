# 덱 UI/UX 정돈 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 덱 페이지의 타이포·표면·컨트롤 위계·카드 기능층을 스펙(specs/2026-07-19-deck-uiux-design.md, 시안 v6)대로 정돈 — 기능·API·데이터 완전 불변, 표시 전용.

**Architecture:** Task 1이 토큰(globals.css)·공용 컴포넌트(ui.tsx)·아이콘(XIcons)을 먼저 깔고, Task 2~6은 **서로 겹치는 파일이 없어 병렬 실행** 가능. Task 7이 통합 검증(빌드·테스트·헤드리스 스크린샷)과 커밋을 담당.

**Tech Stack:** Next.js 16(주의: `node_modules/next/dist/docs/` 먼저 확인) + Tailwind CSS v4(@theme CSS-first 토큰) + React 클라이언트 컴포넌트.

## Global Constraints

- **표시 전용**: fetch 호출·상태 로직·API·DB 접근 코드를 바꾸지 않는다. JSX 구조와 className만 변경.
- **테스트**: 렌더 레벨 테스트 부재가 리포 관행 — 새 테스트 없음. 기존 `npm test` 135/135와 `npm run build`가 깨지지 않아야 함.
- **타이포 토큰만 사용**: `text-content`(15px)/`text-ui`(13px)/`text-caption`(11px). 임의 `text-[Npx]` 금지. 예외: ColumnSettings 모달 제목 20px(X 타이틀 스케일).
- **볼드 규율**: `font-bold`(700)는 컬럼 제목·작성자명·사이드바 활성 내비(X 관례)만. 활성/판정/기회주제는 `font-medium`(500).
- **강조색 규율**: x-blue = 링크·주요 액션 버튼·신규 신호(NEW/진행바)·활성 탭 밑줄만.
- **표면 문법**: 회색(`bg-x-surface`) = 덱 도구층(헤더·패널·해시태그 스트립·사이드바·카드 풋터), 흰색 = X 콘텐츠.
- **병렬 실행 규칙**: Task 2~6의 서브에이전트는 **git 명령 금지**(작업 트리 편집만). 커밋은 Task 7에서 컨트롤러가 수행. 각 에이전트는 자기 담당 파일 외 수정 금지.
- 커밋 메시지는 한국어 `feat(x-research): ...` + `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.

```tsx
'use client';
import type { ButtonHTMLAttributes, ReactNode } from 'react';

// 경량 디자인 시스템 (spec §5) — 덱의 버튼은 이 4변형만 사용
// primary = 파랑(주요·비용 액션 1개), subtle = 테두리, ghost = 호버만, icon = 원형 아이콘
const VARIANT = {
  primary: 'bg-x-blue px-3 py-1 font-medium text-white hover:bg-x-blue-hover',
  subtle: 'border border-x-border-strong bg-white px-3 py-1 hover:bg-x-hover',
  ghost: 'px-2.5 py-1 text-x-secondary hover:bg-x-text/5',
  icon: 'p-1.5 text-x-secondary hover:bg-x-blue/10 hover:text-x-blue',
} as const;

export type ButtonVariant = keyof typeof VARIANT;

export function Button({ variant = 'subtle', className = '', children, ...props }:
  { variant?: ButtonVariant; children?: ReactNode } & ButtonHTMLAttributes<HTMLButtonElement>) {
  return (
    <button {...props}
            className={`rounded-full text-ui transition-colors disabled:opacity-50 ${VARIANT[variant]} ${className}`}>
      {children}
    </button>
  );
}

// 분석 패널 공통 골격 — 제목(500) + 설명 캡션 + 닫기, 도구층 표면 (spec §5)
export function PanelShell({ title, sub, onClose, children }:
  { title: string; sub?: ReactNode; onClose: () => void; children: ReactNode }) {
  return (
    <div className="border-b border-x-border bg-x-surface px-3 py-2 text-ui">
      <div className="flex items-baseline gap-2">
        <p className="font-medium">{title}</p>
        {sub && <span className="min-w-0 truncate text-caption text-x-muted">{sub}</span>}
        <button onClick={onClose} aria-label="닫기"
                className="ml-auto shrink-0 rounded px-1 text-x-secondary hover:bg-x-border">✕</button>
      </div>
      {children}
    </div>
  );
}
```
