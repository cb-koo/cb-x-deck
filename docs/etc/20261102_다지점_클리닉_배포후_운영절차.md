## 배포 순서
1. cb-x-deck 먼저 (빌드 중 마이그레이션 085가 먼저 적용됨, 추가만 하는 마이그레이션)
2. 그다음 익스텐션

## 배포 후 운영 입력 (벤자민, 클라이언트 > 지점 탭)
1. **지점 이름**: 기존 '본점' 행 이름을 명동점/신사점 중 하나로 바꾼다. 기존 예약이 어느 지점 것인지 **담당자 확인 필요**. 나머지 지점은 새로 추가한다.
2. **지점별 운영시간**
   - 신사점: 월–금 10:00–20:00 (점심 13:00–14:00) / 토 10:00–16:00 / 일 휴무
   - 명동점: 월–금 10:30–20:00 / 토 10:30–16:30 / 일 휴무
3. **양식 등록**
   - 폼 양식: 8문항(스펙 §2)
   - 시트 양식: `- 인플루언서 계정 링크: {{profileUrl}}` 와 `- 인플루언서 팔로워 :` (값 없이) 포함
   - 저장 시 '다른 지점에도 적용' 질문에 맞게 선택
4. **협찬 항목 메모**: '협찬 항목' 탭에 입력 (익스텐션에는 읽기 전용으로 보임)

## 수동/실환경 확인 필요 항목

- G1–G3, H5: 브라우저 확인 (지점 탭, 예약 등록·수정 지점 선택, 운영시간 안내 [다시 시도])
